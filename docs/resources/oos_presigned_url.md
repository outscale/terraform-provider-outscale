# outscale_oos_presigned_url Resource

Manages a pre-signed URL.

For more information on this resource, see the [User Guide](https://docs.outscale.com/en/userguide/Introduction-to-OOS.html).  
For more information on this resource actions, see this [User Guide's section](https://docs.outscale.com/en/userguide/Creating-a-Pre-Signed-URL.html).

## Example Usage

### Generate a download URL for an object

```hcl
resource "outscale_oos_bucket" "bucket01" {}

resource "outscale_oos_object" "object01" {
  bucket  = outscale_oos_bucket.bucket01.id
  key     = "object.txt"
  content = "Object content"
}

resource "outscale_oos_presigned_url" "download01" {
  bucket     = outscale_oos_bucket.bucket01.id
  key        = outscale_oos_object.object01.key
  method     = "GET"
  expiration = "15m"
}

output "download_url" {
  value     = outscale_oos_presigned_url.download01.url
  sensitive = true
}
```

## Argument Reference

The following arguments are supported:

* `bucket` - (Required) The bucket for which the URL applies.
* `expiration` - (Optional, Computed) (Default: `15m`) How long the generated URL remains valid, expressed as a Go duration string such as `"15m"` or `"1h"`.
* `key` - (Optional) The object key for the signed request. Required when `method` is `GET` or `PUT`.
* `method` - (Optional, Computed) (Default: `GET`) The HTTP method authorized by the URL: `GET`, `PUT`, `HEAD`, or `DELETE`.

## Attribute Reference

The following attributes are exported:

* `expires_at` - The expiration timestamp calculated by the provider, in RFC 3339 format. Once the URL has expired, the provider plans replacement of this resource on the next Terraform plan or apply.
* `id` - A unique identifier generated by the provider to track this URL in Terraform state.
* `url` - (Sensitive value) The generated pre-signed URL.
